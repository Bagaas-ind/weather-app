# Synoptic - Premium Web Weather App 🌤️🌪️

![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)

**Synoptic** adalah aplikasi cuaca berbasis web modern yang dirancang dengan antarmuka *Glassmorphism* (efek kaca transparan) yang premium.

## 🌐 Live Demo
Cek website yang sudah online di sini: **[https://apkcuac.netlify.app ]** 

## ✨ Fitur Utama
- **Desain Premium**: Latar belakang dinamis yang berubah sesuai cuaca dan wilayah.
- **Mode Gelap/Terang**: Dukungan *Dark Mode* elegan dan *Light Mode* segar.
- **Data Real-Time**: Mengambil data dari API Open-Meteo.
- **Prakiraan 5 Hari**: Menampilkan cuaca harian ke depan.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS
- **API**: Open-Meteo API
