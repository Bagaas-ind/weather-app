Synoptic adalah aplikasi cuaca berbasis web modern yang dirancang dengan antarmuka premium. Menggunakan latar belakang dinamis (bintang di malam hari, awan di siang hari) tanpa gambar yang mengganggu, sehingga informasi cuaca tetap menjadi fokus utama.

## 🌐 Live Demo
Cek website yang sudah online di sini: 
👉 **[https://cuaca-synoptic.vercel.app](https://cuaca-synoptic.vercel.app)**

## ✨ Fitur Utama
- **Desain Premium:** Latar belakang dinamis yang berubah sesuai cuaca dan waktu (siang/malam).
- **Notifikasi Hujan:** Peringatan otomatis di layar jika diprediksi akan turun hujan di wilayah tersebut.
- **Mode Gelap/Terang:** Dukungan *Dark Mode* elegan dan *Light Mode* segar.
- **Info Cuaca Lengkap:** Suhu saat ini, suhu terasa, kelembapan, kecepatan angin, dan peluang hujan (persentase).
- **Prakiraan Mendatang:** Menampilkan prakiraan cuaca per jam dan prakiraan 5 hari ke depan.
- **Mobile Responsive:** Tampilan yang dioptimalkan untuk HP, tablet, dan desktop.

## 🛠️ Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel
